# UPVenta

SPA híbrida de **inventario y ventas** para un emprendimiento pequeño. El emprendedor registra la venta en el celular apenas ocurre.

Proyecto de **Aplicaciones móviles — UPB**, Entrega 2: App híbrida.

## Cómo ejecutar

```bash
npm install
npm run dev
```

```bash
npm run build
npm run preview
```

## Cuenta demo

## Pantallas

Login, productos y stock, registrar venta, resumen del día, alertas, historial y créditos.

Datos en `localStorage`. Funciona sin internet.
