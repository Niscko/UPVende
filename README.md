# UPVenta

SPA híbrida de **inventario y ventas** para un emprendimiento pequeño. El emprendedor registra la venta en el celular apenas ocurre.

Proyecto de **Aplicaciones móviles — UPB**, Entrega 2: App híbrida.

## Cómo ejecutar

```bash
npm install
npm run dev
```

```bash
npm run build
npm run preview
```

## Cuenta demo

- Correo: `demo@upventa.app`
- Clave: `demo123`

## Pantallas

Login, productos y stock, registrar venta, resumen del día, alertas, historial y créditos.

Datos en `localStorage`. Funciona sin internet.

## Prototipo Figma

Pantallas listas para importar: abre `figma/tablero.html` en el navegador.

1. En [figma.com](https://www.figma.com) crea un archivo **UPVenta**.
2. Crea frames **iPhone 14** (390×844), uno por pantalla.
3. Captura cada teléfono del tablero (`Cmd + Shift + 4`) y pégalo en su frame.
4. En **Prototype**, conecta: Login → Inicio → Productos / Vender / Hoy / Historial, y la campana → Alertas.
5. Share → *Anyone with the link* → pega el enlace aquí:

https://www.figma.com/file/REEMPLAZAR
